# Student Academic Analysis

A Power BI project designed to provide insights into student performance. This dashboard visualizes key academic metrics to help educators and administrators understand the relationships between study habits, attendance, and exam performance.

## Features

- **Hours Studied vs Exam Scores:** Scatter plot to identify correlation between study time and performance.
- **Sleep Hours vs Exam Scores:** Scatter plot/line chart showing the impact of rest on academic results.
- **Attendance % vs Exam Scores:** Bar chart to highlight the importance of class attendance.
- **Previous Score vs Current Exam Score:** Line or column chart to track improvement or decline.
- **Exam Score Trend:** Progress/decline visualization for each student.
- **Moving Average of Exam Scores:** Smooths out variations to reveal general performance trends.

## Files

- **student_academic_analysis.pbix**: Power BI dashboard file.
- **Assets/student_academic_analysis.png**: Preview image of the dashboard.

## How to Use

1. Open `student_academic_analysis.pbix` in Power BI Desktop.
2. Interact with the dashboard filters and visuals to explore insights.
3. Use slicers to filter by student, exam, or other parameters.
